# 06-shiftboard（交班台）

交班台 — 班次责任与在途批次交接：班次登记 → 在途批次归属 → 交班互斥办理 → 交班前后对账。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓贴源/明细/汇总分层。  
**也不是** OA 考勤排班后台、电商订单、报表 CSV 看板。

## 启动

本地开发：

```bash
# 后端
cd backend
pip install -r requirements.txt
set DATA_DIR=%CD%\data
set FIXTURES_DIR=%CD%\..\fixtures
uvicorn app.main:app --host 127.0.0.1 --port 10600

# 前端
cd frontend
npm install
npm run dev
```

| 入口 | 地址 |
| --- | --- |
| 前端 | http://127.0.0.1:5600 |
| 接口 | http://127.0.0.1:10600 |

## 主链

登记班次与值班人 → 在途批次归属当前班次 → 发起交班（全仓同时仅一单进行中）→ 完成交班整批过户（同事务追加流转账本）→ 交班对账报告与清单/批次同源 → 抽查对账物化差异

## 流转账本与派生约定（三个择一）

1. **账本存储**：选用**独立只追加流转账本表** `transfer_ledger`（不采用按日分区表）。每一笔成功过户在**同一事务**追加账本行（时间、单号、业务键、from、to、方向）；归属不一致时补偿回拨也在同一事务追加 `回拨` 行。SQLite 触发器硬禁 UPDATE/DELETE，账本只追加；禁止先改归属再异步补账本，禁止无账本行却归属已变。
2. **流量派生**：选用**查询时聚合账本**（不建物化日汇总表）。「今日交入/交出」与任意时段净流量一律由 `transfer_ledger` 聚合派生（`GET /api/ledger/flows?start=&end=`，start 含 end 不含，缺省今日）；当前在途数以 `batches` 表为准；交班服务不另维护任何计数器。
3. **差异物化**：选用**独立对账差异表** `reconcile_diffs`（不采用报告快照列）。`POST /api/reconcile/run` 抽查账本过户行，沿业务键追到链尾，核对能否由接班方在途、后续结清或再交链解释；解释不了的业务键写入 `reconcile_diffs`（只追加，触发器禁改删），禁止为抹平而删改账本。

## 界面约定

页面文案全部中文；入口：总览 / 班次 / 在途批次 / 交班办理 / 交班记录 / 流转账本 / 交班对账。

| 仓 | 骨架 |
| --- | --- |

| Changeflow | 事件序→缺口→Sink 游标 |
| Checklane | 入检→规则→隔离签发 |
| Tiercraft | 贴源→明细→汇总→层间对账 |
